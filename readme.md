# SVAR Gantt for React — Zustand State Management Demo
Same [SVAR Gantt](https://docs.svar.dev/react/gantt/) + React + Vite app, wired up with different state management libraries. One branch per library.

## Branches

| Branch | State management |
|--------|-----------------|
| [main](https://github.com/svar-widgets/react-gantt-demo-vite/tree/main) | React |
| [redux](https://github.com/svar-widgets/react-gantt-demo-vite/tree/redux) | Redux |
| [zustand](https://github.com/svar-widgets/react-gantt-demo-vite/tree/zustand) | Zustand |
| [mobx](https://github.com/svar-widgets/react-gantt-demo-vite/tree/mobx) | MobX |
| [xstate](https://github.com/svar-widgets/react-gantt-demo-vite/tree/xstate) | XState |
| [jotai](https://github.com/svar-widgets/react-gantt-demo-vite/tree/jotai) | Jotai |
| [valtio](https://github.com/svar-widgets/react-gantt-demo-vite/tree/valtio) | Valtio |

## Run locally

```bash
npm install
npm run dev
```
